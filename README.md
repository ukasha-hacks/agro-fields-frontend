# Agro Field frontend

Next.js, TypeScript and Tailwind frontend for the Agro Field local-data backend.

Implementation is published in cumulative stage branches:

| Branch | Scope |
| --- | --- |
| [stage/01-foundation](https://github.com/ukasha-hacks/agro-fields-frontend/tree/stage/01-foundation) | Setup, typed API, URL state and validation |
| [stage/02-map-explorer](https://github.com/ukasha-hacks/agro-fields-frontend/tree/stage/02-map-explorer) | Full-screen Uganda map, overlays, charts and replay |
| [stage/03-farmer-workflow](https://github.com/ukasha-hacks/agro-fields-frontend/tree/stage/03-farmer-workflow) | Full implementation, farmer forms, results, PDF and help |

Use the final branch for the complete project and setup instructions. Each stage has its own README and development record. Data access remains on the FastAPI backend; no forecast or unreviewed crop benefit is claimed.
